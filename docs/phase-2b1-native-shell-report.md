## Native trial and confirmed UI eligibility defect

Fresh operator confirmation: present at the unlocked Mac, available for the
four-minute test and normal cleanup. The exact executable was launched directly
with a new `test-profile-2b1-` profile and supported `BREAKPAD_DUMP_LOCATION`
Crashpad isolation. Evidence: `logs/phase2b1-ui-end3_z48`. Browser PID **20381**,
start `Sun Oct 25 02:08:05 2026`; full kernel executable/start/profile identity
was recorded. No app-selection or implicit launch operation occurred.

Read-only `CGWindowListCopyWindowInfo` filtered to the owned PID produced window
34194; each capture rechecked PID/start/executable. `screencapture -x -l 34194`
read that window only. A tiny local Swift utility queried WindowServer metadata
without NSApplication activation/selection/launch calls. The compiled process's
loaded library path was verified with lsof as the rebuilt output-root
`libchrome_dll.dylib`. Private captures were inspected before copying two safe
images to [native review evidence](../design/review/native-2b1/README.md).
These are real native captures **before the correction**, showing upstream
colors and the test fixture/Settings. They are not proof of final Orbit colors.

The trial exposed a deterministic mistake in the initial patch: its eligibility
guard required `FrameType::kChromium`. At the pinned source,
`BrowserNativeWidgetMac::UseCustomFrame()` (`browser_native_widget_mac.mm:842`)
returns true only for picture-in-picture windows. `BrowserWidget::GetColorProviderKey`
(`browser_widget.cc:520`) consequently sets `kNative` for ordinary macOS browser
windows. Therefore the original guard excludes the intended window. This explains
why the loaded customization library produced the upstream-looking shell. This
is a confirmed source-level UI eligibility defect, **not** a diagnosis or fix of
the historical shutdown watchdog.

`0002-orbit-macos-native-frame.patch` changes the guard to `kNative`, updates all
baseline/exclusion regression keys to match real macOS windows, and adds a case
preserving upstream colors for nonnative/PiP frames. The exact old manifest state
was checked first; the complete two-patch series passed scratch replay. Only the
checked suffix was applied, then final hashes/modes/inventory were verified.
No reset, cleanup or relaxation of the applicator's pristine precondition was
used. One temporary review root first failed canonical-path validation because
macOS aliases /var; retrying with its resolved path passed before source writes.
