# Trinol Orbit asset provenance

orbit-mark.svg, the inline three-path orbit artwork and icons.js are original
vector drawings created for this Trinol Browser design phase. Icons use a
20-unit grid and 1.6-unit round strokes. The orbit mark uses a 64-unit viewBox;
its three intersecting paths are the brand motif. No Arc, Safari, Dia, Linear,
Google or other proprietary browser asset was copied.

Typography uses installed system UI fonts (-apple-system/BlinkMacSystemFont,
Segoe UI, sans-serif). No font file is bundled or redistributed. Shortcuts use
plain fictional letter tiles; no third-party logo artwork is included. Product
naming and asset distribution still require the owner's normal legal/license
review. No new distribution license is granted by this document.
